# Origami Path

Mobile Android application for learning origami through step-by-step guides, personal model creation, and progress tracking.

<img width="994" height="552" alt="image" src="https://github.com/user-attachments/assets/bca8b5b6-f0df-4823-9917-bbe956a66667" />

## Features

- Firebase Authentication (Login & Registration)
- Browse built-in origami models
- Step-by-step origami instructions
- Track completed models
- Create custom origami models
- Edit and delete personal models
- Upload step images using Camera or Gallery
- Daily Origami Idea powered by Unsplash API
- Personal origami galleries (7, 14, or 21 days)
- Daily photo progress tracking
- Automatic reminder notifications
- Firebase Firestore integration
- Local JSON storage

## Technologies

- Kotlin
- Jetpack Compose
- MVVM Architecture
- Firebase Authentication
- Firebase Firestore
- Unsplash API
- WorkManager
- Kotlin Coroutines
- StateFlow
